# Submission intake template

Copy this block and fill it in once per item, or once per batch if
everything in the batch shares the same source, date and rights holder.
Save it as a `.md` file next to the material, e.g.
`refmaterial/<corridor>/<source>/SUBMISSION.md`, or paste it into an email
or PR description.

```

- Date of photo/plan/record (or "unknown", estimate welcome):

- Link, if from somewhere online:

## Submitter
- Name (as you'd like it credited, or "anonymous"):

```

## Notes for whoever processes this

- If "rights status unknown" or "research only" is ticked, the file stays
  in `refmaterial/` for internal reference and is **not** copied into
  `game/img/` or any public-facing asset, regardless of how useful it is.
- Cross-check against existing sources before treating a submission as
  fact — see `docs/ROADMAP.md` on structures being decisions, not
  invented content. A single photo or memory is a lead, not a citation.
- When in doubt about rights, treat as research-only and ask the
  submitter to clarify rather than guessing.
